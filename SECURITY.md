# Security

AdVera is self-hosted and, for now, has **no authentication**: it is meant for one user on a trusted local network ([ADR 0015](docs/adr/0015-authentication-deferred-single-user.md)). Do not expose it to the internet.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting (the **Security** tab of the repository, **Report a vulnerability**), with the version or commit, the steps to reproduce and the impact you expect. Never include real meeting audio, transcripts or credentials in a report.

You will get an answer as soon as possible; a fix is published with a note in the release once it is ready.
