## Brand & Style

This design system delivers an engineering-grade, high-density environment tailored for autonomous meeting intelligence and verifiable knowledge graphs. Marrying the keyboard-first speed of Raycast with the precision observability of enterprise telemetry dashboards, the interface projects authoritative control, unyielding stability, and cognitive clarity.

The visual style is characterized by:
- **Obsidian Depth & Neural Radiance**: Deep slate foundations accented by razor-sharp electric indigo luminescence, creating distinct hierarchical tiers without visual clutter.
- **Precision Engineering**: Micro-scale UI density, sub-pixel borders, fine-gauge structural dividers, and monospaced cryptographic-style indicators that ground dynamic AI outputs in objective reality.
- **Focused Utility**: High-efficiency ergonomics built for rapid scanning, deep analytical scrutiny, side-by-side verification, and low-latency interaction.

## Colors

The color palette anchors the system in dark slate and obsidian tones, calibrated to prevent eye fatigue across high-density sessions while maintaining strict WCAG AAA contrast ratios for vital technical telemetry.

### Core Architecture
- **Canvas Base (`#0A0D12`)**: The foundational canvas plane reserved for structural frame gutters and deep background regions.
- **Surface Primary (`#11151C`)**: The workhorse panel layer hosting active panes, transcripts, and document sections.
- **Surface Elevated (`#181E29`)**: Dynamic utility modules, hover layers, popovers, and sticky playback rails.
- **Surface Subtle (`#1E2633`)**: Inactive badges, recessed command fields, and table headers.

### Accents & Signal Indicators
- **Primary Neural Accent (`#6366F1`)**: Reserved for system intelligence markers, cryptographic verification signatures, and primary activation pathways.
- **Secondary Telemetry Accent (`#38BDF8`)**: Drives audio waveform spikes, live streaming signals, and active speaker focus nodes.
- **Tertiary Insight Accent (`#8B5CF6`)**: Surfaces verified vector memories, persistent entity anchors, and semantic clustering nodes.

### Telemetry Pipeline Tokens
- **Verified / Synced (`#10B981`)**: Confirmed speaker attributions, finalized ledger blocks, and authenticated pipeline states.
- **Pipeline Processing (`#F59E0B`)**: Real-time diarization, vector ingestion in progress, and non-blocking sync queues.
- **Critical Divergence (`#F43F5E`)**: High-risk hallucinations, missing biometric verifications, and compliance flags.

## Typography

The type system prioritizes micro-legibility and geometric fidelity under extreme data load. Geist serves as the universal family across displays, body text, and tabular telemetry, relying on precise OpenType features (slashed zeros, tabular numerals `tnum`, and context-sensitive tracking).

- **Display & Headings**: Tightly tracked, confident geometric cuts designed for immediate spatial anchoring without wasting vertical canvas real estate.
- **Prose & Dialogue**: Optimized line-height-to-size ratios (`body-md` at 13px/20px) guarantee effortless consumption of multi-speaker transcripts over prolonged periods.
- **Telemetry & Diarization**: Metrics, timestamps, and model hashes utilize tabular figures (`font-variant-numeric: tabular-nums`) to prevent alignment jitter during real-time streaming updates.

## Layout & Spacing

The layout model is governed by high information density, fluid split-pane orchestration, and strict 4px grid increments. Content areas maximize display throughput while avoiding boundary confusion.

### Pane Philosophy & Grid
- **Three-Column Modular Dock**:
  1. *Navigation / Session Tree (Left)*: Fixed 240px collapsable dock for fast channel and session traversal.
  2. *Interactive Stage (Center)*: Fluid pane featuring the acoustic waveform timeline pinned to the bottom and synchronized transcript streams above.
  3. *Verifiable Memory Sidebar (Right)*: 380px contextual inspector displaying knowledge graph projections, verified citations, and action item ledgers.
- **Breakpoints**:
  - *Compact / Mobile (< 768px)*: Collapses into single-stream stack with swipe-accessible verification drawer and bottom sheet audio controls.
  - *Standard / Laptop (768px – 1280px)*: Two-pane configuration (Transcript Stage + Contextual Drawer).
  - *Wide / Desktop (> 1280px)*: Full tri-pane orchestration with continuous real-time knowledge synthesis visibility.

## Elevation & Depth

This design system eschews traditional high-cast shadows in favor of architectural surface layering, low-contrast inner borders, and high-frequency edge highlights.

- **Stacking Surfaces**:
  - `Layer 0 (Canvas)`: `#0A0D12` pure backdrop.
  - `Layer 1 (Panels & Workspace)`: `#11151C` bounded by 1px solid `#222B38`.
  - `Layer 2 (Floating Inspect Panels & Popovers)`: `#181E29` bounded by 1px solid `#2E3A4D` with a subtle top edge specular gradient (`rgba(255, 255, 255, 0.05)`).
- **Edge Highlighting**: Modals and dropdowns feature a sub-pixel highlight ring (`inset 0 1px 0 0 rgba(255, 255, 255, 0.07)`) paired with an ambient shadow (`0 12px 32px -4px rgba(0, 0, 0, 0.6)`).
- **Neural Focal Glow**: Focused interactive elements (e.g., command bars, active memory citations) project a precise 4px indigo glow blur (`box-shadow: 0 0 0 1px #6366F1, 0 0 16px -2px rgba(99, 102, 241, 0.35)`).

## Shapes

The shape language utilizes a soft, technical curvature (`roundedness: 1`). At an exact 4px (0.25rem) base radius, UI elements maintain strict geometric definition, resisting organic playfulness in favor of functional precision.

- **Interactive Core (Inputs, Action Buttons, Badges)**: 4px (`rounded`).
- **Cards, Panels, Floating Windows**: 8px (`rounded-lg`, 0.5rem), maintaining internal corner harmony with nested 4px controls.
- **Status Markers & Scrubber Knobs**: Pure circular profiles (`rounded-full`) reserved strictly for biometric user indicators, live pipeline status dots, and scrub anchors.

## Components

### Buttons & Interactive Triggers
- **Primary Neural Button**: Solid `#6366F1` surface with `#FFFFFF` text, 0.25rem corner radius, 1px top specular border (`rgba(255, 255, 255, 0.2)`), and high-contrast font metrics. Hover triggers subtle luminosity shift to `#4F46E5`.
- **Secondary Ghost Button**: Surface `#181E29`, border 1px `#2E3A4D`, text `#94A3B8`. Hover introduces white text and `#222B38` border illumination.
- **Compact Keyboard Trigger**: Height 24px, embedded hotkey cue (e.g., `⌘K`) rendered in muted monospace glyphs inside an internal `#222B38` badge.

### Precision Telemetry Badges & Chips
- **Diarization Pill**: Displays speaker name with confidence score (e.g., `Alex D. 98.4%`). Background `#181E29`, hairline border `#222B38`, leading dot tinted to speaker channel color.
- **Verification Seal**: Compact inline badge indicating zero-knowledge proof or local hash storage. Uses semantic emerald tint with green beacon dot (`#10B981`).

### Input Fields & Command Strip
- **Obsidian Search Input**: Dark inset background `#0A0D12` with 1px border `#222B38`. On focus: 1px `#6366F1` ring with soft ambient indigo aura. Padding: `0.5rem 0.75rem`.
- **Command Palette**: Centered modal overlay floating with `#181E29` surface, hairline `#2E3A4D` perimeter, and integrated fuzzy-search execution list.

### Synchronized Transcript Block
- Composed of timestamp (`11px` tabular text), speaker indicator tag, and verified utterance block. Hover over any segment highlights synchronized audio waveform position and surfaces micro-actions (copy quote, link to memory, extract task).

### Waveform Audio Scrubber
- Persistent lower dock rendered in `#11151C` with top edge `#222B38`. Displays multi-channel audio amplitude bars: inactive audio uses `#2E3A4D`, active spoken fragments glow with `#38BDF8`, and verified insight moments flag along the track with `#6366F1` micro-markers.
